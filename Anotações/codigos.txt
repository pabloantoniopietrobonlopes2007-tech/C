Estruturas de repetição: executam blocos de código repetidamente enquanto uma condição for verdadeira. 
Elas utilizam uma variável de controle (iniciada, testada e incrementada/decrementada) para determinar o número de iterações, interrompendo o loop quando a condição se torna falsa
	while(enquanto): repete uma ação até que sua condição se torne falsa
		Estrutura: for (inicialização; condição; incremento) { comandos }

	do-while(fazer enquanto): mesmo que while, mas o comando é executado no minimo 1 vez, mesmo que a condição for falsa;
		estrutura: do{comando}
			   while(){}

	for(para):

For (Para): Ideal para quando o número de repetições é conhecido. Estrutura: for (inicialização; condição; incremento) { comandos }.
While (Enquanto): Usado quando não se sabe exatamente quantas repetições ocorrerão. Verifica a condição antes de executar o bloco.
Do-While (Repita): Semelhante ao while, mas garante a execução do bloco pelo menos uma vez, pois testa a condição no final.
